# Visit Prep Workflow

Visit Prep is the primary provider continuity workflow surface. It compresses operational history into a calm, appointment-ready view.

## Philosophy

Visit Prep helps a caregiver answer:

- what changed recently
- what needs review
- which medications or vitals matter for the visit
- which artifacts should be available
- which care notes add useful context

It is an operational preparation flow, not a clinical recommendation system.

## Contents

Visit Prep may include:

- recent changes
- continuity signals
- medication changes
- key vitals trends
- recent uploads or artifacts
- care notes
- provider-facing continuity summaries
- export or share actions

## Scanability

Visit Prep should prioritize short sections, factual copy, and clear source attribution. A caregiver should be able to review it quickly before an appointment.

## Boundaries

Visit Prep must not include:

- diagnosis generation
- treatment recommendations
- predictive interpretation
- hidden AI conclusions
- provider portal behavior
