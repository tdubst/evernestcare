# Onboarding Philosophy

Evernest Care onboarding should reduce caregiver load. It should help a family establish enough structure to coordinate care without forcing a large intake process.

## Principles

- Start with the care subject.
- Invite the first helper early.
- Add only essential medication and background context.
- Introduce the continuity timeline before advanced features.
- Keep every step reversible and optional when possible.

Onboarding should feel calm, plain, and supportive. It should avoid clinical bureaucracy, giant forms, and dense health questionnaires.

## Ideal First-Use Flow

1. Create care subject.
2. Invite caregiver or supporter.
3. Add medications and basic history.
4. Establish continuity timeline.
5. Generate first provider-ready summary.

## Progressive Setup

Setup may continue after onboarding. Caregivers should be able to add artifacts, vitals, notes, and appointments as real life provides them rather than completing a full profile before seeing value.

## Continuity-First Onboarding

The first experience should make it clear that Evernest Care is a family coordination operating system, not an EHR, diagnostic product, or provider portal. The goal is to preserve operational context so care handoffs become less chaotic.

## Non-Goals

- Enterprise setup flows.
- Comprehensive medical intake.
- Insurance workflows beyond factual storage.
- Diagnostic triage.
- Provider account provisioning.
