# Navigation Continuity Model

Evernest Care navigation should follow the caregiver mental model and avoid duplicate top-level surfaces.

## Bottom Navigation

### Today

What matters now?

### Calendar

What is coming next?

### Messages

What are caregivers coordinating?

### Vault

What must be remembered or stored?

### Circle

Who is involved in care?

## Today Surface

Today should contain operational workflows, not duplicate bottom navigation. Appropriate surfaces include:

- Visit Prep
- Continuity Signals
- Medications
- Vitals
- Recent Changes
- Care Notes

## Vault Surface

Vault owns document capture and memory workflows:

- Upload File
- Scan Document
- Add Photo
- Attach Artifact

Artifacts remain operational continuity objects when linked to the timeline.

## Non-Goals

- Feature fragmentation.
- Redundant tabs.
- Repeated workflow icons.
- Dashboard overload.
- Duplicate navigation patterns.
